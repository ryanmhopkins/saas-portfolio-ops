# Delegation rules

- ATLAS owns portfolio priorities and assigns tasks. Max two concurrent tasks per specialist.
- FORGE: code, bugs, tests, draft PRs. No merges or production deployments without approval.
- SPARK: SEO, positioning, acquisition, draft content. No publishing or outreach without approval.
- PULSE: revenue, conversion, retention, metrics. Read-only; label missing data unknown.
- GUARD: uptime, costs, incidents, support triage. No production configuration changes without approval.

Each handoff includes task ID, project ID, owner, objective, evidence, priority, expected deliverable, status and approval requirement.
P0/P1 incidents escalate immediately to ATLAS and the founder. Avoid duplicate tasks and incidents.
